# candidates/ — 미채택 후보 자산

이 폴더는 공식 자산(`assets/` 루트, `src/assets/`)과 분리된 **미채택 상태**의 자산을 보관한다. 여기 있는 파일은 프로덕션에서 사용하지 않는다.

## roomting-map-pin-unadopted.svg

- **상태**: 미채택 (2026-08-01 R자 모노그램 심볼 공식 채택 시점 기준)
- **앱 참조**: 0건 — `src/`, `public/`, `index.html`, `scripts/` 어디에서도 import/링크되지 않음
- **범위**: 지도 핀 전용 브랜드 자산(티어드롭 핀 + 흰 심볼)이나, 지도 기능은 현재 요청서 MVP 범위 밖이라 도입 여부 자체가 결정되지 않은 상태. 실제 지도 화면(`MapExplore`)은 이 SVG 대신 CSS 말풍선(`price-marker`)만 사용 중.
- **색상**: `fill="var(--pink, #F26559)"` — **구 토큰**. `--pink`는 2026-08-01에 코드베이스에서 완전히 제거되어, 이 파일을 그대로 어딘가에 embed하면 fallback `#F26559`로만 렌더링된다. 공식 팔레트(`--coral` #FF6F61 / `--coral-action` #F26559) 기준으로 재검토 없이 사용 금지.
- **프로덕션 사용 금지**: 채택 여부가 결정되기 전까지 `src/assets/`나 화면 코드에 복사·import하지 않는다. 채택 시 이 폴더에서 꺼내 공식 브랜드 컬러로 색상 갱신 후 이동한다.
